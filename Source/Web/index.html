SELECTED ARTWORK

Open Tile editor and click an image. Drag to move; use the corner handle to resize and the top handle to rotate. Choose Linked / mirrored copies to keep related motifs together.

Linked copies share scale and follow the layout. Mirrored copies move in opposite directions and rotate oppositely across the mirror.

Set the copy count and arrangement in the source library. Source sets layout uses those counts automatically.
