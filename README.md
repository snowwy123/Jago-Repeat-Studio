# Jago Repeat

Make patterns that carry on.

Build a seamless tile from your artwork. Arrange motifs by hand or try variations on a layout, then check how the edges meet. A repeat can move as well as sit still.

## Give it a try

Install with Jago Suite, or extract the portable download and open **Jago-Repeat.exe**.

Add a motif and switch between the tile and repeat views. When the pattern feels right, save the editable project and export the tile or loop.

[Find Jago Suite and downloads](https://jagosuite.co.uk/)
