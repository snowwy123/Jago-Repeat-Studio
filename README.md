# Jago Repeat 1.13.0

Make something that carries on.

Build seamless patterns from artwork, arrange motifs and repair repeating textures. Explore generated layouts, then keep control of the details.

[Website](https://jagosuite.co.uk/) · [Downloads](https://github.com/snowwy123/Jago-Repeat-Studio/releases/latest)

## Get started

Download **Jago-Repeat-v1.13.0.zip**, right-click it and choose **Extract All**. Open **Jago-Repeat.exe** from the extracted folder. Keep supporting files together. No installer is needed for the portable edition. Open **Jago-Repeat.html** for offline browser use in current Edge or Chrome.

Windows requires 64-bit Windows and .NET Framework 4.8. Windows studio hosts require Microsoft Edge WebView2 Runtime.

Read **Documentation/Jago-Repeat-Guide.pdf** for an illustrated introduction, tools and connected workflows. Save editable projects as well as finished exports.

## Tools

- Tile dimensions, spacing, motif sizes, rotation, mixing and controlled variation.
- Linked/mirrored sets, overlap protection and editable frozen occurrences.
- Independent seeds and layout locks; reusable repeat recipes.
- Wrap-aware texture painting, erasing and cloning; seam repair and repeat proofing.
- Still tiles, larger filled sheets and moving pattern exports.
- Prominent ordered, flowing and graphic exploration families with related variations.
- Save eight named project directions with previews and restore them later.
- Bulk movement, scale, rotation, alignment and distribution of motif groups.
- Move proof seams to the centre and export a guide proof without changing the tile.
- Comparison cancellation, playback and frozen-source restoration fixes.
